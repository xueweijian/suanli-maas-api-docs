对话 POST /v1/chat/completions

curl -s $BASE/chat/completions -H "Authorization: Bearer $SUANLI_API_KEY" \
  -H 'Content-Type: application/json' \
  -d '{"model":"deepseek/deepseek-v4-flash-0731-free", \
       "messages":[{"role":"user","content":"hi"}],"max_tokens":32}'
# → {"model":"DeepSeek-V4-Flash-0731","choices":[{"message":{"content":
#    "Hello! How can I help you today?"},"finish_reason":"stop"}}],...}
mineru 用 chat 调回空 content；asr 回 language None<asr_text> 占位符——都是"假 200"，别用。embedding / rerank 吃 body-400，生图吃 404。

向量 POST /v1/embeddings

curl -s $BASE/embeddings -H "Authorization: Bearer $SUANLI_API_KEY" \
  -H 'Content-Type: application/json' \
  -d '{"model":"qwen/qwen3-embedding-8b","input":"hello"}'
# → {"model":"Qwen3-Embedding-8B","data":[{"embedding":[...4096 维...]}],
#    "usage":{"prompt_tokens":2,"total_tokens":2}}
4b = 2560 维，8b = 4096 维。OpenAI SDK 的 client.embeddings.create 直连可用。

排序 POST /v1/rerank

curl -s $BASE/rerank -H "Authorization: Bearer $SUANLI_API_KEY" \
  -H 'Content-Type: application/json' \
  -d '{"model":"qwen/qwen3-reranker-8b","query":"cat", \
       "documents":["a cat","a dog"]}'
# → {"results":[
#   {"index":0,"relevance_score":0.2114,...},  # a cat
#   {"index":1,"relevance_score":0.1017,...}]}
别写成 /v1/v1/rerank（base 已含 /v1）。

生图 POST /v1/images/generations

# 很慢！超时至少 180s
curl -s --max-time 180 $BASE/images/generations \
  -H "Authorization: Bearer $SUANLI_API_KEY" -H 'Content-Type: application/json' \
  -d '{"model":"black-forest-labs/flux.1-krea-dev", \
       "prompt":"a small orange cat sitting on a wooden table, photorealistic"}' -o flux.json
python3 -c "import json,base64;d=json.load(open('flux.json')); \
open('cat.png','wb').write(base64.b64decode(d['data'][0]['url'].split('file://',1)[1]))"
# → {"created":...,"data":[{"url":"file://iVBOR..."}]}  # base64 PNG 1024×1024

转写 POST /v1/audio/transcriptions

curl -s --max-time 120 $BASE/audio/transcriptions \
  -H "Authorization: Bearer $SUANLI_API_KEY" \
  -F model='qwen/qwen3-asr-1.7b' -F file=@voice.wav
# → {"text":"...","usage":{"type":"duration","seconds":2}}
multipart 表单，16kHz 单声道 wav 最稳。合成 2s 正弦波实测 200（无语音故 text 为空，但 seconds=2 证明链路通）。

坑位（5 个亲踩）

1. 业务拒绝藏 body 里：embedding / rerank 用错端点时 HTTP 仍 200，error 在 body（code 400）。判通 = 有 choices/data/results 且无 error。
2. 生图 chat 直接 404：别重试，换 images 端点。
3. 生图很慢：60s+ 才回包，超时设 180s。
4. 间歇 DNS 抖动：Errno -3 Try again，重试 2-3 次即过。
5. App 列表缓存：App 显示 11 个是旧的，线上 14 个，refresh 为准。
